Tandem is licensed under GPL-3.0-only (Tandem-GPL-3.0.txt).

It bundles these libraries as separate jars inside META-INF/jars, so each can be replaced with a modified version:

- Elementa (https://github.com/EssentialGG/Elementa), LGPL-3.0: Elementa-LGPL-3.0.txt
- UniversalCraft (https://github.com/EssentialGG/UniversalCraft), LGPL-3.0: UniversalCraft-LGPL-3.0.txt
- Kotlin standard library (https://github.com/JetBrains/kotlin), Apache-2.0: Kotlin-Apache-2.0.txt
- TwelveMonkeys ImageIO (https://github.com/haraldk/TwelveMonkeys), BSD-3-Clause, to read mod icons in WebP: TwelveMonkeys-BSD-3-Clause.txt

Tandem's core includes a Java port of KCP (https://github.com/skywind3000/kcp), MIT, for game traffic over a punched UDP path: KCP-MIT.txt

The LGPL-3.0 adds to the GPL-3.0, whose text is in Tandem-GPL-3.0.txt.

Font: Inter (https://github.com/rsms/inter), SIL Open Font License 1.1: Inter-OFL-1.1.txt. Bundled as Inter 4.1's static TTFs, unchanged.
